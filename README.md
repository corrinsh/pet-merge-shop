# 萌宠合成店 🐾

宠物合成经营小游戏原型（订单制 · 66 关）

## 玩法

点两只同等级萌宠 → 合成更高级的 → 满足顾客订单 → 星级通关！

- 8 级进化：蛋 → 小鸡 → 小鸭 → 兔 → 猫 → 狗 → 熊猫 → 麒麟
- 6 大章节：开业大吉 → 奇怪客人 → 森林秘境 → 都市分店 → 云端牧场 → 传说之巅
- 每章 11 关，含 Boss 大订单关与缓冲赚钱关

## 在线试玩

打开 https://corrinsh.github.io/pet-merge-shop/ 直接玩，无需安装。

## 技术

单文件 HTML5（HTML + CSS + JS），SVG 手绘宠物，localStorage 存档，零依赖零素材成本。
